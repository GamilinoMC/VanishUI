A simple vanish plugin with a clean UI!

## Features

## Commands

➜ /vanish

## Features

- Short HUD message if you vanish/unvanish
- FormAPI also included
- Clean-UI
- Permissions

## Permissions
| **Permissions** | **Description**               | **Default** |
|-----------------|-------------------------------|-------------|
| vanish.use      | Permission for the Vanish UI! | Operator    |
